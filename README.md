# Анализ сигнала на основе методов машинного обучения и преобразований Фурье

## Задание
Для успешного прохождения проектно-технологической практики необходимо, используя методы машинного обучения, провести анализ ряда сигналов, полученных от датчиков, для решения задачи классификации.

Для выполнения теоретической части исследования необходимо:
- описать, что такое задача классификации;
- описать, как используются преобразования Фурье для анализа сигнала;
- описать работу используемых для решения задачи классификации моделей машинного обучения;
- описать работу дополнительных алгоритмов для решения задачи;
- привести описание программных продуктов, используемых в работе;

В практической части работы необходимо:
* установить необходимые программные продукты;
* написать алгоритм позволяющий определить изменения в графике данных, используя преобразования Фурье;
* отрисовать график разным цветом в зависимости от классификации;
* добавить к анализу круговую диаграмму, показывающую сколько времени в какой стадии находился сигнал;
* проанализировать реальные данные;
* сделать выводы по проделанной работе.

## Использование приложения
Для использования приложения необходимо:
1. Клонировать репозиторий на свою машину:
```
git clone https://github.com/BuKohn/Practice3
```
2. Установите зависимости:
```
pip install requirements.txt
```
3. Запустить Jupyter Notebook:
```
jupyter notebook signal.ipynb
```
4. Выполнить все ячейки notebook последовательно
